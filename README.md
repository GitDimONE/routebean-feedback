# RouteBean feedback

Thanks for trying RouteBean early. This is where problems and ideas go.

- **Something broke or looks wrong:** [report a problem](../../issues/new?template=problem.yml)
- **You wish it did something:** [share an idea](../../issues/new?template=idea.yml)

A screenshot helps more than anything else. Please don't post passwords or anything private; this page is public.

If the site is down, you don't need to report it. An automatic check notices within about 15 minutes and opens an issue labelled `outage`.
