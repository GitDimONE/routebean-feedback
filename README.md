# RouteBean feedback

Report a problem, suggest a feature, or follow product progress here.
English and Russian are welcome. Можно писать по-русски.

- [Report a problem](https://github.com/GitDimONE/routebean-feedback/issues/new?template=problem.yml)
- [Suggest a feature](https://github.com/GitDimONE/routebean-feedback/issues/new?template=idea.yml)
- [Browse existing feedback](https://github.com/GitDimONE/routebean-feedback/issues)
- [Public roadmap](https://github.com/users/GitDimONE/projects/2)

This repository and its attachments are public. Remove personal information,
passwords, access tokens, and private screenshots before submitting. For a private
report, use **Help → Send feedback** in RouteBean and keep visibility **Private**.
You do not need a GitHub account to send feedback from the app.

Error reports go through private evidence review and Jev-assisted triage before
becoming a proposed fix. Proposals require owner review before implementation;
public responses, statuses, roadmap entries, and release announcements require
explicit owner confirmation. Russian reports follow the same workflow.

The `roadmap` label identifies deliberately selected, public product entries.
An empty roadmap means no items have been published yet. Private reports and
implementation issues are never automatically copied here. Product announcements
and the website changelog will explain shipped changes.

Availability checks also open `outage` issues. Existing reports, attachments,
and outage monitoring are preserved.
